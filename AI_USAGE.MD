# AI Usage Documentation

## Tools used
- ChatGPT for initial flask routes in app.py with /companies route, and /companies/edit route
- Used ChatGPT to generate the initial HTML structure for companies.html and edit_company.html, including forms for adding and editing company information
- ChatGPT was used to assist with remaining flask routes for remaining tables when running into issues
- ChatGPT for general guidance and explaining concepts, code, and certain errors
- ChatGPT used for job matching implementation 
- AI was used to provide a cleaner UI 

## Key Prompts
- "Implement initial flask routes for /companies route, and /companies/edit route to serve as a baseline"
- "Generate initial HTML structure for companies.html and edit_company.html"
- "Explain the implementation of these flask routes and how they fit in with the bigger picture"
- "Explain the decisions made when implementing the job matching algorithm"

## What worked well
- AI provided useful explanations to understand certain implementations and how they fit together 
- AI generated good initial html structures, CRUD routes, and styling 

## What I modified
- Fixed various naming mismatches when compared to my actual table columns, and table names 
- Built off of the initially generated HTML structures and flask routes to implement them for the rest of the tables

## Lessons learned
- Work incrementally, and always test code before moving on
- Use AI effectively by asking questions and understanding code generated by AI to improve the overall learning experience 
- Always overlook any code generated by AI since it can often contain small mistakes that can cause bugs
